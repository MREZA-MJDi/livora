# Shipping location data

`iran-provinces-cities.json` contains 31 Iranian provinces and the city names supplied by the upstream dataset. Duplicate city names within each province are removed.

The source maintainer notes that the list was collected from multiple sources and may omit or misassign some cities. The checkout therefore includes a “my city is not listed” entry and permits the customer to enter a city manually. The list is a province/city selector, not a live carrier-coverage lookup; shipping coverage and price must still be confirmed by the store's fulfilment policy.
